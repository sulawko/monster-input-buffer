What people
ask most.

No complicated setup, no jargon. If something goes wrong, drop by the Discord and we'll help.

Is it safe?+

It is an unofficial mod made by SuLawko. Download it only from this page or the official repository and, if the SHA-256 hash is published, check it matches your file. If your antivirus complains, that is common with this kind of file: ask on Discord if in doubt.

Is it cheating? Can I use it for records?+

Monster Input Buffer is an input buffer: it helps with the timing of your clicks. Which mods are accepted for records or rankings is decided by each community, list or moderator, so check their rules before submitting a record. For playing and practicing, no problem.

Can I get banned for using it?+

It is not an official RobTop mod and we do not control third-party rules (lists, servers or tournaments). Use it at your own discretion and check the rules wherever you plan to compete.

Is it compatible with other mods?+

It is made for Geometry Dash 2.208. If you notice a conflict with another mod, tell us which one on Discord or open a report on GitHub and we will look into it.

It doesn't work, what do I do?+

Make sure your game is version 2.208 and that you followed the install steps. If it still doesn't work, write to us on Discord or open a report on GitHub.

Does it cost anything?+

No. It is free and it will stay that way.
